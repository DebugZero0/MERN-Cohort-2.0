## 🧠 About the Course

**Cohort 2.0 by [Sheryians Coding School](https://sheryians.com)** is a full-fledged **Web Development Bootcamp** designed to transform you into a **Job-Ready Full Stack Developer**.  
You’ll build real-world projects, understand core fundamentals, and deploy apps using modern technologies like **React**, **Node.js**, **MongoDB**, and more.  

This repository will contain **all my assignments, exercises, and projects** from the course — organized by module and linked with their **live previews** inside their respective folders.  

---

## 🧩 Course Roadmap

> A hands-on, project-based learning journey that goes from **HTML basics** to **full-stack mastery** with the **MERN stack**.

<details>
<summary>📍 <b>Module 1: HTML, CSS & Web Fundamentals</b></summary>

- Understanding Web & Internet  
- HTML structure, forms, semantics  
- CSS styling, layout techniques (Flexbox, Grid)  
- Responsive design and media queries  
- CSS Animations, Transitions, and Pseudo-selectors  
- Mini Projects:
  - 🌐 Portfolio Page  
  - 🧱 Landing Page Clone  
</details>

<details>
<summary>🎨 <b>Module 2: Advanced CSS & Tailwind</b></summary>

- Tailwind CSS fundamentals  
- Utility-first approach  
- Building modern UIs faster  
- Custom configurations and themes  
- Responsive grids with Tailwind  
- Mini Projects:
  - 🪩 Modern UI Website  
  - 📱 Responsive Navbar Design  
</details>

<details>
<summary>⚙️ <b>Module 3: JavaScript (Core + Advanced)</b></summary>

- Variables, Data Types, Operators  
- DOM Manipulation & Event Handling  
- Functions, Scope, and Closures  
- ES6+ Features (let, const, arrow functions, destructuring, etc.)  
- Promises, Async/Await  
- Fetch API & Error Handling  
- Mini Projects:
  - 🎯 To-Do App  
  - 🎲 Interactive Game  
</details>

<details>
<summary>🧠 <b>Module 4: React.js</b></summary>

- Components, Props, and State  
- React Hooks (useState, useEffect, etc.)  
- Conditional Rendering  
- Forms & Events  
- Context API and State Management  
- Routing with React Router  
- Deploying React Apps  
- Projects:
  - ⚡ Portfolio (React Version)  
  - 🛒 Mini E-Commerce UI  
</details>

<details>
<summary>🌍 <b>Module 5: Backend with Node.js & Express</b></summary>

- Node.js Basics & Package Management (npm/yarn)  
- Express Framework Fundamentals  
- REST API Development  
- Middleware and Routing  
- Authentication (JWT, Bcrypt)  
- Connecting to MongoDB with Mongoose  
- Error Handling and Validation  
- Project:
  - 🔐 Authentication System  
  - 🗂️ CRUD App API  
</details>

<details>
<summary>💾 <b>Module 6: Database - MongoDB</b></summary>

- Introduction to NoSQL & MongoDB  
- CRUD Operations  
- Schema Design & Relationships  
- Aggregation Pipeline  
- Atlas Cloud Integration  
- Mini Project:
  - 📘 Notes App Backend  
</details>

<details>
<summary>🚀 <b>Module 7: Deployment & Version Control</b></summary>

- Git & GitHub Essentials  
- Branching, Merging & PR Workflow  
- Hosting:
  - Frontend → Netlify / Vercel  
  - Backend → Render / Railway  
  - Database → MongoDB Atlas  
- Environment Variables & Config  
</details>

<details>
<summary>💼 <b>Module 8: Final Projects & Career Prep</b></summary>

- Building Full Stack Projects (MERN)  
- Project Structure Best Practices  
- Debugging, Optimization & Testing  
- Resume + GitHub Optimization  
- Interview Preparation & Mock Tests  
</details>
